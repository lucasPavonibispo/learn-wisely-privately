# LearnWise Hub

.













"Act as an expert Full-Stack Software Engineer, EdTech Specialist, and Data Privacy Officer. Build a fully functional, highly responsive, and modern Progressive Web App (PWA) designed for interactive micro-learning across any subject while strictly complying with data protection regulations (such as LGPD and GDPR).



Core Features Required:



Data Privacy & Compliance (LGPD/GDPR First):



Local-First Architecture: Store all user data (progress, points, custom notes) locally in the browser using localStorage. No personal data should be sent to external servers without explicit consent.



Privacy Policy & Terms Modal: Include an easily accessible Privacy Notice detailing what data is stored, why, and how users can clear it.



User Data Control: Provide a simple "Clear All My Data" button allowing users to execute their right to erasure at any time.



Subject & Level Selection: Allow users to type any topic they want to learn or pick from predefined categories (e.g., Coding, Languages, Science, History), then choose their difficulty level (Beginner, Intermediate, Advanced).



AI-Powered Learning Modules: Generate dynamic content structured into:



Flashcards: Short, digestible core concepts with a flip animation.



Interactive Quiz: Multiple-choice questions with instant feedback and detailed explanations for wrong answers.



Cheat Sheet: A concise summary/bulleted reference guide for the topic.



Gamification System: Track user progress with a point system (XP), daily streaks, and completion badges stored securely in localStorage.



UI/UX Design: Mobile-first layout, dark mode by default, clean typography, smooth page transitions, and accessible UI controls.



Tech Stack: Single-page application using HTML5, Tailwind CSS for styling, and modular Vanilla JavaScript (or React if using modern web builders).*



Provide the complete, self-contained, production-ready code with clean architecture and inline documentation."
